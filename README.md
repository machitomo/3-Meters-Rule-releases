# 3 Meters Rule!

<img src="artwork/3_meters_rule_cover.png" width="300" alt="3 Meters Rule! ドット絵のロゴ・ペンギン・雪山">

南極の雪原で、人懐っこいペンギンを避けながら観測基地へ帰る、オリジナルのGame Boy Color用逃走アクションです。
ダッシュと物資を使い、全3ステージをクリアして合計タイムを縮めてみてください。

## ダウンロード

[最新リリース](https://github.com/machitomo/3-Meters-Rule-releases/releases/latest) の **Assets** から取得してください。

- `3_meters_rule_vX.Y.Z.zip`: ROM・パッケージ絵・遊び方をまとめたZIP
- `3_meters_rule.gbc`: ROM単体
- `3_meters_rule_cover.png`: パッケージ絵単体
- `SHA256SUMS.txt`: ダウンロードファイルのSHA-256チェックサム

ZIPを展開し、mGBA、SameBoy、iOSのDeltaなどのGBC対応エミュレーターでROMを開いてください。
詳しい遊び方はZIP内のREADME、または [配布版の遊び方](release/README.md) にあります。

## 操作

十字キーで移動、Aでアイテム、Bでダッシュ、STARTで開始・ポーズ・リトライ。
各ステージでペンギンに3回触れるとゲームオーバーです。ペンギンは攻撃できません。
轍をたどって基地へ帰り、全3ステージをクリアすると合計タイムを表示します。
